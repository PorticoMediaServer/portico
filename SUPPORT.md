# Support

Portico is a free project that I build and maintain myself. I'm happy to help when I can, but I can't promise it.

## Getting help

- **Bugs:** [open an issue](https://github.com/PorticoMediaServer/portico/issues). Search first in case someone's already reported it, and include your Portico version, platform, how you installed it, and any logs. Remove passwords, personal details and private addresses first.
- **Questions and ideas:** post in [Discussions](https://github.com/PorticoMediaServer/portico/discussions).
- **Anything that shouldn't be public:** email [admin@getportico.tv](mailto:admin@getportico.tv).
- **Security problems:** report them privately, as described in [SECURITY.md](SECURITY.md). Please don't open a public issue.

## What to expect

Using Portico, opening an issue or emailing me doesn't create any obligation to respond, investigate, fix something or ship an update, and there's no response time or release schedule. Security reports work the same way.
