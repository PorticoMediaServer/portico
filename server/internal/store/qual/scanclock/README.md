actual current-authority browse page showing that retained subject in the same
library AND database incarnation. The report retains the original reference and
matched IDs for joining raw evidence. Commit return, traversal discovery/EOF, historical replay and errors do
not substitute for a serving observation. The collector uses existing merged
writer/read value types; it opens no database and issues no authority or command.

process clock. Manifest fields are declarations to join to retained raw evidence,
not a source/binary/host attestation performed here. This collector is not a
receipt verifier, visibility reader, driver factory or clock/restart bridge.
Unit records are fabricated controls, never measurements.

filename visibility and both Basic clocks remain null: durable directory/frontier
completion and Basic hooks are separate gates. Do not report the sampled target
as a whole-library first/all milestone, and do not turn missing fields into zero.
