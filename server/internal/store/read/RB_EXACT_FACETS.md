# Exact numeric facet preparation

This harness-only phase2 composition reduces eligible entities into exact year or decade counts. `BeginNumericFacets` starts one governor-held preparation; callers retain the opaque operation and call `Advance` for each independently admitted 1,024-raw-row snapshot. A full quantum is pending, including a full final quantum: only an exhaustion probe marks the result ready. No snapshot, statement or raw row survives a quantum.

The fixed year index supplies first, equality-tail and next-key statements. Each raw row advances the cursor before retirement/age eligibility; both year and decade categories include only years 1800–2199 (zero and out-of-range values are omitted). The bounded reducer combines contiguous value runs without a growing map. `ValueMemberships` counts eligible entities with a value; it does not claim the universal exact browse total. Preparation uses the existing conservative default policy and refuses restricted containers/custom recipes.

The cache reserves physical bytes through the preparation profile, captures the full comparable read fence, and allocates fixed vectors only after charging twice the actual retained fence-string bytes. Query identity includes database, viewer token, library, kind, field and original time anchor. An identical active start attaches to its existing producer and does not renew the lease, context or cursor. An expired attachment refuses instead of silently starting another lifetime.

`Page` uses the original LIVE/output custody and a fresh authorized snapshot. It checks the full fence and current token horizon, then copies at most 200 values to independent output memory before the governor releases the publication conflict lease. Ready alone does not release it. Later cached pages reauthorize and compare the whole fence until the original absolute deadline. Cancel, stale source, denial, governor invalidation and expiry produce no values. A foreground writer, security, media or capture can invalidate preparation; discretionary conflicts remain excluded until the first authorized handoff. Explicit `Close` joins the producer lock, drops buffers, then retires physical memory.

The logical test profile adds separately funded preparation bytes; it changes no phase1a composition or hardware qualification. Runtime tests cover the real SQLite handoff, parked ready conflict, paginated exact counts, revocation and moving source. The Capture test covers all three statements under analyzed and unanalyzed statistics and exports source-bound evidence on a standard runner.

Remaining work: automatic source-drift restart (at most two, preserving the original deadline), string/membership facets, intersected filters, personal orders, selection/rank consumers and large hierarchical order producers. This family does not claim those semantics, the 1M-seed latency budgets, the statement-budget follow-up in #1357, or whole-server resource qualification. Qualification targets are the 1,024-row advance, first ready page and cached continuation under the canonical 1M seed, including active discretionary publication and foreground interruption.
