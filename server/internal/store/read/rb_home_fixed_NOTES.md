## Implemented exact small scopes

* new_on_server folds available eligible episodes into shows, songs into albums,
  and book files into books; standalone movies retain their public identity when
  no provider-equivalence facts exist. The complete merged shelf sorts newest
  first, public encoded work ID breaking ties, then takes the newest100 works.
  Restricted dates and delivery grouping use ONLY currently admitted, whole
  available leaves, so a hidden newest episode cannot change the visible date or
  navigation target. Unrestricted show chronology uses the actual maintained
  last_content_added_at fact. A one-hour adjacent addition gap defines delivery:
  one episode navigates there; one season's group navigates to that actual season;
  multi-season or undated groups retain the actual show. Parent revisions/public
  IDs, membership and every chosen leaf are included in final proof.
* continue composes actual native movie state, current binding duration, unfinished
  millisecond position, current activity visibility and playback-specific dismissal.
  The accepted three-second end exclusion applies. Default maximum40 is used ONLY
  when no owner library document exists. It does not relabel leaf ContinueWatching.
* listen_next resolves each album's newest eligible actual song activity. An active
  song resumes there; an ended song advances in complete disc/track/id order to the
  next available admitted song. Actual audiobook resumes use the book's retained
  current resume child, current leaf state and complete source duration. Active
  works precede each library's last100-work recent fallback; overlap keeps the
  actual activity target. A finished album may still occur in the recent tier.
* continue_books composes current audiobook book/file resumes and sparse native
  personal state. The book must name the actual resume child; completed, ended,
  dismissed, wrong-unit and out-of-duration positions cannot qualify.

A source binding is conservative: exactly one whole link, current item/asset/link
