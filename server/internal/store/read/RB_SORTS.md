# Accepted scalar browse orders

`BrowseReader.SortedWindow` adds ten statically compiled source orders to the
existing harness-only browse reader: year, duration, communityRating,
criticRating, episodeCount, latestAired, releaseDate, aired, trackNumber and
fileSize. Kind applicability follows the existing browse vocabulary; fileSize
requires owner authority. Unsupported kinds and policies fail closed.

Use `RBBrowseDefinitions` for inert registry composition, then Capture on the
actual Reader before creating the registry/snapshot pool. No shared definition
list or shipped route is modified. The60 definitions repeat canonical partial
predicates exactly and use SEARCH-only first/equality-tail/next-key statements
in both directions, preserving native integer/REAL/text values and ID ties.
The compressed comparison baseline covers both statistics profiles and populated
and empty cohorts. Captured statements are not execution authority by themselves.

Compose the call inside `ConsumeForeground`, retaining the output until all
encoding/client consumers finish. The merged initial/final authority/library
fence, original deadline and LIVE provenance checks apply unchanged. A private
scalar cursor binds viewer/query/order/revisions and cannot be mixed with a
BrowseCursor. Each lookup fetches at most64 raw positions before eligibility;
retired/denied positions consume and advance that same budget. An empty raw
window with a continuation is incomplete work, never a complete zero-match page.
No OFFSET, row-tuple predicate, source-to-user write or extra durable copy is
introduced. Ready pages contain at most40 values.

No-retry recipe counts are11 statements for first pages and11–12 for
continuations across2 physical windows. Those exceed the proposed10-statement
whole-route target and remain unqualified debt. Ready, VM, paired foreground,
maximum legal bodies,1M and2GB budgets are NOT qualified by these functional
controls or plan captures.

This slice intentionally retains the merged policy envelope: supported local
principal, no blocked-label/account-policy recipe, complete age-summary fence,
and no restricted-container aggregate use. Restricted leaf age rejection uses
the existing predicate. Complete author/Reading/playlist pivots, nullable added
and resolution streams, seeded random rotation, personal/hierarchy/default
sorts, Home composition, exact facets and preparation/cache composition remain
separate slices. Title order remains the existing dual-article `Window` recipe.
