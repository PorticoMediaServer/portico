# Receiver font

`manrope-var-latin.woff2` is the canonical bundled Manrope variable font, copied
unchanged from `web/src/kit/fonts/manrope-var-latin.woff2` on server main.
It supplies weights 200–800, including the receiver's specified 500, 700 and 800.
The source is the Google Fonts Manrope v20 Latin slice, re-subset with FontTools.
Manrope is licensed under the SIL Open Font License 1.1 in `OFL.txt`.

Source: https://fonts.google.com/specimen/Manrope
Project: https://github.com/googlefonts/manrope
