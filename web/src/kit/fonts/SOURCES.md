manrope-var-latin.woff2 is the byte-exact official Google Fonts Manrope v20
Latin variable asset used by the approved web mock-ups:
https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
SHA-256: a30ddcd349703aff7464c34bef3fffdff405ee50c113440d7c8693c02d210972

The font's own version is 4.504 and its weight axis covers 200–800; fonts.css
exposes the approved UI range of 400–800 as Manrope. Vite resolves the relative
asset URL to a same-origin hashed file. No remote or data font URL is used.

The official asset retains all 216 code points reported by Fontconfig for the
former bundled re-subset and adds U+0102 (217 total). The raw cmap also retains
both existing control/sentinel entries. It removes no existing web-font coverage. Scripts outside this Latin slice continue to use the existing system
fallback; this change does not narrow their coverage.

The previous FontTools re-subset remains preserved in Git (blob
4ce8a2520a25d8241144f569816a0c55eeeb9ac2), with SHA-256
b11ce306f8de710b83eac83c0f3fe0820159437f7d9a24179441092ec616f8ed.
Its glyph metrics differed from the approved official asset at the same CSS
weight and size. No CSS spacing or weight compensation is applied.
