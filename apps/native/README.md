# Native clients

One React Native tvOS application covers phones, tablets, Apple TV, Android TV and Fire TV. Shared code is read directly from the root packages tree.

Start with the root [README](../../README.md) and [build instructions](../../BUILDING.md). [Native platform notes](../../docs/native/BUILDING.md) cover the Android and Apple toolchains. Install this app's own lockfile with `npm ci --legacy-peer-deps --workspaces=false`.
