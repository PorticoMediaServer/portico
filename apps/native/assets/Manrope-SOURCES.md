Manrope 400, 500, 600 and 700 are the existing unmodified bundled static
version 4.504 assets, licensed under OFL-Manrope.txt.

manrope-800.ttf is the unmodified static Manrope ExtraBold version 4.504 from:
https://github.com/googlefonts/manrope/blob/46f712fc77cec7cbe22a86d077254fc43fc78f23/fonts/ttf/manrope-extrabold.ttf
Its upstream licence text is included in OFL-Manrope-800.txt, with trailing
whitespace removed.

React Native fontFamily names (PostScript names on Apple; copied asset names
on Android):

| Weight | fontFamily | Source asset |
| --- | --- | --- |
| 400 | Manrope-Regular | manrope-400.ttf |
| 500 | Manrope-Medium | manrope-500.ttf |
| 600 | Manrope-SemiBold | manrope-600.ttf |
| 700 | Manrope-Bold | manrope-700.ttf |
| 800 | Manrope-ExtraBold | manrope-800.ttf |

These are static faces; consumers select the matching family for each weight.
The Apple projects register the source filenames through UIAppFonts and their
Resources build phase. Android copies the files to assets/fonts under the
fontFamily names above.
