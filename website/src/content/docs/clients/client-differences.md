---
title: Why controls differ between apps
description: Understand which Portico behaviour is shared and which controls depend on the device.
category: clients
order: 5
audience: Everyone
updated: 2026-07-12
---

Portico apps share the same account permissions, libraries, and playback intent. They do not all use the same screen layout or media player.

A phone supports touch, background audio, and mobile network settings. A television needs predictable remote focus and ten-foot text. A browser has its own media and security limitations. Native apps use the platform's secure storage and playback integration.

The server still makes the final authorization and playback decisions. A missing control can mean that the account lacks permission, the server does not advertise the capability, or the current platform cannot perform the action safely.

Check the documentation for the affected app before assuming that a control has moved or failed.
