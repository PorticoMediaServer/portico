Portico Cloud never carries your video or audio. An authorized Portico app streams private media directly from the Portico Server that owns it, over a verified local or remote connection.

## Technical details

Portico Cloud helps an account find the servers it can use and supplies signed connection information. It does not relay, tunnel, cache, inspect, transcode, or store the media stream.

This boundary keeps the server owner in control of storage, upload capacity, playback work, and library permissions. It also means that remote playback depends on the server and its internet connection being available.

Artwork and metadata served by the Portico Server follow the same authorization boundary when they belong to a private library.
