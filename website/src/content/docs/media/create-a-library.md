Open **Settings**, go to the library settings, and choose **Add library**. Give the library a clear name, select its media type, and add one or more folders.

The media type controls how Portico scans, matches, and presents the files. A Movies library and a TV Shows library should not point at the same mixed folder.

## Before saving

- Confirm that Portico can read each folder.
- Confirm that each folder contains the selected media type.
- Review the accounts that should be able to use the library.
- Choose scan and metadata options appropriate for the collection.

Save the library and let the first scan finish before making several changes at once. Open a few items to check titles, artwork, episode grouping, and playback.
