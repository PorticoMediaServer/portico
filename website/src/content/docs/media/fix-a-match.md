title: Fix an incorrect match
description: Correct the title or metadata selected for a movie, show, album, or other library item.

audience: Server owners
updated: 2026-07-12
---

First check the file and folder names. A manual correction can fix the display, but clean names prevent the same problem after a rebuild or migration.

Open the item's actions and choose the match or metadata editor. Search with the exact title and release year, compare the available results, and select the correct one.

## If no result is right

Confirm that the library type matches the file, the server can reach its configured metadata providers, and the title exists in the selected source. For uncommon or personal media, use local metadata and artwork where supported rather than forcing an unrelated match.

After changing a match, review the title, year, artwork, episode or track hierarchy, and available media file before applying the same correction to other items.
