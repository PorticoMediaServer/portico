---
title: Sign-in problems
description: Check the account, server membership, password, device time, and session state.
category: troubleshooting
order: 6
audience: Everyone
updated: 2026-07-12
---

Confirm that you are using the same Portico Account that accepted the server invitation. A different email or sign-in method can create or select a different account.

Use the normal password-recovery flow instead of asking the server owner to share or reset an owner credential. If multi-factor authentication is enabled, keep recovery codes available before replacing a device.

Check the device date and time. Secure sessions and signed connection documents can fail when the clock is far from the actual time.

If sign-in succeeds but the server is absent, the problem is membership or connection rather than the password. Follow [Server not found](/docs/troubleshooting/server-not-found/).
