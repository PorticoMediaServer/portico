---
title: Server not found
description: Restore a missing or offline server in a Portico app.
category: troubleshooting
order: 2
audience: Everyone
updated: 2026-07-12
---

Confirm that the server computer is on, Portico Server is running, and its media storage is available. Try opening Portico from a browser on the same network.

If the server works locally, check whether the affected account still belongs to it. Sign out and back in only after confirming the account and server membership, because replacing a valid session can hide the original error.

For remote access, review the published route, public reachability, and certificate state. VPNs, changed router addresses, firewall updates, and expired connection information can affect only the remote path.

If the server was restored or moved, confirm that it retained the expected server identity rather than appearing as a new unrelated server.
