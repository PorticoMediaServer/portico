---
title: Report a product issue
description: Provide reproducible client or server evidence without sharing secrets or private media.
category: developers
order: 5
audience: Developers
updated: 2026-07-12
---

Identify the Portico component, version, operating system or device, runtime mode, and exact action that failed. Include the expected result and what happened instead.

Reduce the problem to the smallest sequence that still fails. State whether it occurs for every account, library, media item, server, network, or client.

Include a request identifier, relevant bounded log excerpt, and playback decision when they apply. Remove tokens, cookies, emails, public or private addresses, filesystem paths, and media names that should remain private.

Security vulnerabilities should follow [Report a security issue](/docs/security/report-a-security-issue/) instead of a public product issue.
