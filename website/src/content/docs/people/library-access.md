---
title: Manage library access
description: Choose which libraries an account can browse, search, play, and save.
category: people
order: 2
audience: Server owners
updated: 2026-07-12
---

Library access is assigned per account on the Portico Server. A person can belong to the server without receiving every library.

When access is removed, the library should disappear from normal navigation and search for that account. Existing Saved items or history do not override the current permission.

New libraries need an explicit access review. Do not assume that a restricted account should automatically receive a collection created later.

Use a normal viewer session to verify changes. Owner and administrator accounts can see controls that are intentionally absent for the person you are testing.
