Library access is set per account on the Portico Server. Belonging to a server doesn't have to mean access to every library.

## Choose libraries

1. Open **Settings → Server → People → Accounts** and select the person's username.
2. Select **Edit** beside **Libraries they can see**.
3. Leave **All libraries, including ones added later** selected for unrestricted library access, or clear it and select specific libraries.
4. Select **Save**.

Profiles can have further restrictions within the account's access. A profile can't grant itself a library its account can't use.

## When you add a library

Accounts set to **All libraries, including ones added later** receive new libraries automatically. Accounts with a specific library list don't. Review that choice whenever you create a library.

## When you remove access to a library

The library disappears from that person's normal navigation and search. Saved items and history don't override current permissions.

## Check your changes

Test from a normal viewer session. Owner and administrator controls don't show you what the person can actually see.
