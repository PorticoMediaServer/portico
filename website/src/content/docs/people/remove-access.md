Open **Settings → Server → People → Accounts** and select the person's username.

## Temporarily stop access

1. Select **Edit** beside **Sign-in**.
2. Select **Disable this account** and save.

Disabling keeps the account and its saved data, blocks sign-in and revokes its current credentials. Clear the option to allow the person to sign in again.

## Delete the person

Select **Delete this person** at the bottom of the account record. Read the confirmation before selecting **Delete**.

Deletion removes the server account, its profiles, progress, history, lists and playlists, and signs out its devices. It keeps your media files and recordings. Plays retained in the owner's play history no longer carry the person's name. A linked Portico Account itself isn't deleted; it loses membership of this server.

## Review devices and invitations

Review the devices in the person's account record, or open **Settings → Server → People → Devices**. Block devices you no longer trust. A blocked device is signed out and can't use the server until approved again.

Under **People → Invitations**, revoke any unused invitation that should no longer work. Revoking an invitation invalidates its link and code; it doesn't remove someone who has already joined.

## Keep the access record you need

Review the server's audit records and retention settings when investigating an access change. Keep only the records you need for your server's policy.
