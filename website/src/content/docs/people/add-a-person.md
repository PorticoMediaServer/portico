Give each person their own account for sign-in, devices and security records. Use their profile for progress, My List, history and ratings. Keep the owner account private. See [Accounts and servers](/docs/start/accounts-and-servers/) for the difference.

## Create a server account

1. Sign in as the owner and open **Settings → Server → People → Accounts**.
2. Select **Add account**.
3. Enter a username, profile name and password.
4. Under **Libraries they can see**, choose all libraries or select specific libraries. **All libraries, including ones added later** is selected for a new account unless you change it.
5. Select **Add account** and give the person their server address and sign-in details privately.

They can sign in directly without a Portico Account. See [Connect a Portico app](/docs/clients/connect-a-client/).

## Create an invitation

Invitations created here grant access to all libraries. You can restrict library access only after the person joins. If they must never receive unrestricted access, create a server account with specific libraries instead.

1. Open **Settings → Server → People → Invitations**.
2. Select **Invite someone**.
3. Choose the role. You can enter an email address to label the invitation and a **Portico Account username** to limit who can use it.
4. Select **Create invitation**.
5. Copy the **Invitation link** or code and share it with the person. Portico doesn't send an email.

An unrestricted invitation can be used by anyone who has the link or code. Invitations created here expire after seven days. The recipient can join with their Portico Account, or create a server account when the invitation permits it.

After the person joins, open their account under **Settings → Server → People → Accounts** and edit **Libraries they can see** if they need restricted access.

## Review the person's access

Open **Settings → Server → People → Accounts** and select their username. This is their access record. It shows their role, libraries, sign-in state, limits and devices. Review playback, download and Live TV limits there. Recording permission is managed separately under **Settings → Server → Live TV & Channels → Recording → Who can record**.

Test with a normal viewer account. Confirm that allowed libraries are visible and restricted libraries and administrative actions are hidden.
