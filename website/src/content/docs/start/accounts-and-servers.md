A Portico Account works across servers and is optional. A server account exists only on one Portico Server. Each server keeps its own media library and decides which libraries and actions your account can use.

## One account, several servers

A Portico Account can belong to more than one server. Access on one server doesn't give access to any other server. A server account uses that server's address, username and password; it doesn't automatically become a Portico Account or appear in a Portico Account's server list. See [Connect a Portico app](/docs/clients/connect-a-client/) for both sign-in options.

## Accounts and profiles

An account holds sign-in credentials and server access. Within an account, each profile keeps its own progress, My List, other saved items, history, ratings and preferences on that server. Use a separate profile for each person's viewing choices. A profile can have further restrictions, but can't grant access its account doesn't have.

Owner, administrator and viewer describe the account's role on a server. Roles describe what an account may do on one server; they don't replace profiles.

## Server owner

The owner controls the server: its libraries, people, remote access, maintenance and administrative settings. Keep owner access limited. When you can, use a normal viewer account for everyday watching.

## Administrator

An owner can give administrative permissions to another person they trust. Give them only the access they need for the work they do. Don't use administrative access as a way around library permissions.

## Viewer

A viewer account can browse and play the libraries assigned to it. The active profile keeps the personal viewing choices described above.
