Portico is a personal media server. You install Portico Server on a computer that can reach your media files, add the folders you want to use, and then watch from Portico apps on other devices.

The server does the important work. It scans files, builds libraries, stores account permissions and watch progress, decides how each item should play, and sends media to an authorized app.

## What Portico Cloud does

A Portico Account gives people one identity they can use across their approved servers and devices. Portico Cloud coordinates account security, server membership, and signed connection information. It does not become the home of your media.

After an app verifies a route to a server, server-specific requests and media travel directly between the app and that server. Portico Cloud does not relay, cache, or inspect the stream.

## What you need

- A computer that can stay on when people want to watch.
- Storage containing media you are authorized to use.
- A reliable local network connection.
- A Portico app or modern web browser.

Start with [Choose a server](/docs/start/choose-a-server/) if you have not selected the computer that will run Portico.
