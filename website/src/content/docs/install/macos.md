Download the macOS package from the [Downloads page](/download/), open it, and place Portico in Applications.

## First launch

Open Portico from Applications. macOS may ask you to confirm that you want to run software downloaded from the internet. Follow the system prompt, then complete Portico's first-run setup.

## Folder access

Portico needs permission to read every media folder. If a library folder is on an external disk or network share, confirm that macOS mounts it consistently and that Portico can still read it after a restart.

## Keep the Mac available

A sleeping Mac cannot serve media. Review the Mac's energy settings and the behaviour of external disks before relying on it for other people.

After installation, restart the Mac and confirm that Portico becomes available again without opening the application manually.
