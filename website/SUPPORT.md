# Support and warranty

Portico is provided **"AS IS", without warranty**, to the extent permitted by applicable law. See [LICENSE](LICENSE) for the full warranty disclaimer and limitation of liability.

## Voluntary support

Support is voluntary and offered at the maintainers' discretion. Using Portico, opening an issue, or contacting the maintainers does not create a support obligation. There is no guaranteed response, investigation, fix, maintenance, or update schedule.

Questions, bug reports, and feature requests are welcome in the issue tracker for the affected repository. Search existing issues first and include your Portico version, platform, installation method, and sanitized logs. Help may be offered, but should not be expected.

For private contact that is not suitable for an issue, email [admin@getportico.tv](mailto:admin@getportico.tv). Contacting this address does not guarantee a response or support.

## Security reports

Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md), rather than in a public issue. Security reports are subject to the same voluntary-support policy; no response, resolution, or patch schedule is guaranteed.
